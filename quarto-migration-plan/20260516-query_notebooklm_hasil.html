Cross Reference system

Pertanyaan

Proyek Bookdown saya menggunakan cross-reference dengan pola berikut:

  • Referensi gambar: \@ref(fig:nama-chunk), contoh: \@ref(fig:proses-perencanaan-rasional)
  • Referensi tabel: \@ref(tab:nama-chunk), contoh otomatis dari kbl() dengan caption
  • Referensi section: \@ref(nama-section), contoh: \@ref(analisis-kuantitatif-vs-kualitatif)
  • Referensi section dengan custom ID: \@ref(kasus-elemen-data-terstruktur)

Pola Regex (Regular Expression) untuk Find & Replace Otomatis di IDE/Teks Editor

Gunakan ekstensi regex di pencarian IDE Anda.

Gambar

  • Cari (Find): \\@ref\(fig:([^)]+)\)
  • Ganti (Replace): @fig-$1

Tabel

  • Cari (Find): \\@ref\(tab:([^)]+)\)
  • Ganti (Replace): @tbl-$1

Section/Bab (Eksekusi setelah gambar dan tabel selesai di-replace):

  • Cari (Find): \\@ref\(([^)]+)\)
  • Ganti (Replace): @sec-$1

Penjelasan:

  • Sintaks Referensi Teks: Di Quarto, pemanggilan referensi silang disederhanakan dengan menggunakan awalan spesifik diikuti pengidentifikasi setelah simbol @. Anda tidak boleh lagi menggunakan \@ref(). Quarto mewajibkan adanya awalan tipe (reserved prefixes) untuk entitas referensi, yaitu fig- untuk gambar, tbl- untuk tabel, dan sec- untuk bab/bagian (section).

  • Pengaturan R Chunk Gambar: Pada Quarto, penggunaan opsi di dalam kurung kurawal seperti di R Markdown lawas telah digantikan dengan opsi hash-pipe khusus (#|) yang diletakkan pada awal baris di dalam chunk. Beberapa format penamaan opsi berubah, seperti out.width di Bookdown menjadi out-width di Quarto, dan fig.cap menjadi fig-cap. Opsi echo=FALSE juga ditulis lebih modern menjadi echo: false. Namun, jika Anda hanya menyisipkan gambar statis (tanpa komputasi R), sangat disarankan memigrasikannya menjadi sintaks Markdown native Quarto seperti pada alternatif poin ke-2 agar dokumen lebih bersih dan optimal saat dirender.

  • Label Heading/Section: Pemanggilan @sec-nama-section pada poin pertama baru akan berhasil jika identifier rujukan dari judul/heading aslinya diubah juga. Agar suatu bab atau bagian dapat direferensikan (cross-referenceable), label heading utamanya juga wajib berawalan sec- (contoh: {#sec-nama-section}).

  • Tool/Otomatisasi Konversi: Jika Anda ingin menggunakan tool yang siap pakai, Nick Tierney membuat catatan “Notes on Changing from Rmarkdown/Bookdown to Quarto” yang membagikan berbagai script otomasi konversi Bookdown ke Quarto. Sebagai alternatif praktis, Anda bisa memanfaatkan fitur Find & Replace menggunakan dukungan Regular Expression (Regex) yang ada pada Editor/IDE (seperti Positron, VS Code, atau RStudio). Anda cukup menyalin blok perintah Regex di atas dan mengganti seluruh pola secara massal (klik Replace All). Namun perlu diingat, setelah Find & Replace beres, Anda tetap perlu menambahkan awalan sec- pada definisi label heading secara manual atau memodifikasi regex tambahan untuk pencarian elemen tajuk.
