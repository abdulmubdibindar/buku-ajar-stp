# Statistika Untuk Perencanaan

Ini adalah repositori pengembangan buku ajar berjudul _Statistika Untuk Perencanaan_ yang digunakan di lingkungan Program Studi Perencanaan Wilayah dan Kota, Fakultas Teknologi Infrastruktur dan Kewilayahan, Institut Teknologi Sumatera (ITERA). Buku ini ditulis oleh dosen-dosen pengampu mata kuliah dengan judul yang sama, di antaranya [Muhammad Abdul Mubdi Bindar](https://pwk.itera.ac.id/profile/staf-akademik/31), [Husna Tiara Putri](https://pwk.itera.ac.id/profile/staf-akademik/10), dan [Valendya Rilansari](https://pwk.itera.ac.id/profile/staf-akademik/35).

Buku ini berfungsi sebagai acuan standar dalam pembelajaran di kelas dengan menyajikan konsep-konsep, studi kasus, serta soal evaluasi pembelajaran terkait dengan statistika dalam konteks keilmuan dan keprofesian Perencanaan Wilayah dan Kota. Secara umum, berikut adalah rincian isi dari buku ini:

1. **BAGIAN I: KONSEP DASAR STATISTIKA DALAM PERENCANAAN**
   1. Peran Statistika dalam Siklus Perencanaan
   2. Data Terstruktur

2. **BAGIAN II: STATISTIKA UNIVARIAT**
   1. Analisis Statistik Deskriptif
   2.  Visualisasi Data Kuantitatif
   3.  Pengantar Statistik Inferensial
   4.  Estimasi Parameter
   5.  Uji Hipotesis Parameter Satu Populasi
   6.  Uji Hipotesis Parameter Dua Populasi
   7.  Uji Hipotesis Parameter Lebih dari Dua Populasi

3. **BAGIAN III: STATISTIKA BIVARIAT** 
   1. Korelasi Antarvariabel Nominal
   2. Korelasi Antarvariabel OrdinaL
   3. Korelasi Antarvariabel MetriK
   4. Regresi Linear Sederhana

4. **BAGIAN IV: STATISTIKA MULTIVARIAT**
   1. Regresi Linear Berganda
   2. Analisis Statistik Multivariat Interdependensi
